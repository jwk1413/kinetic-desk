키네틱 데스크는 화면 한쪽에 띄워 두는 투명 이중 진자입니다. 창 프레임은 없고, 오브제만 보입니다.

## 실행

macOS에서:

```bash
npm install
npm run dev
```

메뉴 막대 아이콘(진자 모양, 없으면 `진`)에서 모드와 일시정지·초기화·종료를 고릅니다.

## 조작

- **조작 모드:** 추를 잡아 던지고, 고정점이나 막대를 드래그해 위치를 옮깁니다. 오브제 밖 클릭은 뒤쪽 창으로 통과합니다.
- **감상 모드:** 모든 클릭이 뒤쪽 작업 창으로 통과합니다. 메뉴 막대 아이콘을 누르거나 `⌘⌥P`로 조작 모드로 돌아옵니다.
- **자연히 멈추기 / 움직임 유지:** 감쇠만 적용하거나, 약한 구동력으로 흔들림을 유지합니다.
- 잔상은 기본 꺼짐입니다.

## 구조

이후 모빌 같은 오브제를 넣기 쉽도록 역할을 나눠 두었습니다.

- `src/main` — 투명 창, 항상 위, 클릭 통과, 메뉴 막대
- `src/renderer/src/physics` — 이중 진자 운동
- `src/renderer/src/render` — 2.5D 그리기
- `src/renderer/src/objects` — 오브제 구현
- `src/shared` — 창과 렌더러가 공유하는 상태

## macOS에서 되는 것 / 안 되는 것

지원됨:

- 투명 배경, 테두리 없는 창
- 다른 창 위에 항상 표시, 대부분의 전체 화면 앱 위에도 표시
- 클릭 통과, 메뉴 막대와 단축키로 조작 모드 복귀

제한:

- 게임이 쓰는 완전 독점 전체 화면에는 가려질 수 있습니다.
- 잠금 화면 위에는 그릴 수 없습니다.
- 클릭 통과 중에는 창을 눌러서 돌아올 수 없습니다. 메뉴 막대나 `⌘⌥P`를 사용하세요.
- 픽셀 단위 창 모양은 OS가 직접 지원하지 않아, 오브제 위일 때만 클릭을 받도록 흉내 냅니다. 경계에서 한 프레임 정도 지연이 있을 수 있습니다.
- 이 버전은 Electron이라 네이티브 앱보다 메모리를 더 씁니다. 첫 버전 실행용이며, 이후 가벼운 런타임으로 옮길 수 있습니다.

로그인이나 서버는 없습니다.
